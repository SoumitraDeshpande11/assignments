# Profile Card UI

A Flutter profile card screen built with the core layout widgets — `Column`, `Row`, `Container`, `CircleAvatar`, `Text`, and `Icon` — styled with custom theme colors. Matches the other assignments: white background, one green accent, rounded surfaces.

## Concepts Demonstrated

- `Column` for the vertical card layout, `Row` for stats, contacts, and buttons
- `Container` with custom padding, color, and rounded corners (card, stat boxes, icon chips)
- `CircleAvatar` with initials as the profile picture
- `Text` styling (size, weight, color) and `Icon` usage throughout
- Custom theme colors via constants (`kPrimary`, `kAccent`, `kSurface`) + `ColorScheme.fromSeed`
- Small reusable widgets (`_StatBox`, `_ContactRow`) to keep the build method tidy

## Run

```bash
flutter pub get
flutter run
```
