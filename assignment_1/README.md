# Community Board Game Lending Library

A minimal Dart console application that models a tabletop game lending library.

## Concepts Demonstrated

- Variables: `String`, `int`, `double`, `bool`, `List<Game>`, `Map<String, Member>`
- Functions: named parameters, optional defaults, typed returns
- Loops: `for`, `while`, `for-in`
- OOP: abstract class, inheritance, polymorphism, encapsulation

## Run

```bash
dart pub get
dart run lib/main.dart
```
