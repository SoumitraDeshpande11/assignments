# Flutter & Dart Assignments

Collection of all 8 assignments for the Flutter/Dart course. Each assignment lives in its own subdirectory with its source code, documentation (`DOCUMENTATION.md` / `.docx`), and app screenshots.

## Assignments

| # | Folder | Project | Concepts |
|---|--------|---------|----------|
| 1 | `assignment_1/` | Community Board Game Lending Library | Dart console app, OOP, collections |
| 2 | `assignment_2/` | Exoplanet Catalog Fetcher | Async Dart, Futures, null safety |
| 3 | `assignment_3/` | Responsive Store Dashboard | `ListView`, `GridView`, `MediaQuery`, `Flexible`/`Expanded` |
| 4 | `assignment_4/` | Profile Card UI | Layout widgets, custom theme colors |
| 5 | `assignment_5/` | Todo List App with State | `StatefulWidget`, `setState`, add/delete/mark-complete |
| 6 | `assignment_6/` | Product Listing with Search & Filter | `ListView.builder`, model classes, search/filter state |
| 7 | `assignment_7/` | 3-Screen App with Named Routes | Named route navigation, form validation |
| 8 | `assignment_8/` | API Data Fetcher with Local Cache | `FutureBuilder`, HTTP, `SharedPreferences` cache |

## Git Workflow

Each assignment was developed on its own feature branch (`assignments_1` … `assignments_8`) and merged into `main`, where all projects are integrated as subdirectories.

## Run Any Project

```bash
cd assignment_N
flutter pub get
flutter run          # assignments 1–2 are pure Dart: dart run
```
