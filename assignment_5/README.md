# Todo List App with State

A Flutter todo list built with `StatefulWidget` and `setState`. Design matches the previous assignments: white background, one green accent, flat rounded cards.

## Concepts Demonstrated

- `StatefulWidget` + `State` class holding the task list
- `setState` for every change: add, delete, and toggle complete
- `TextField` with a `TextEditingController` for input (Enter key also adds)
- `ListView.builder` of task cards, with an empty-state message when the list is empty
- Done tasks show a strikethrough and grey text; a live counter shows "X of Y done"

## Run

```bash
flutter pub get
flutter run
```
