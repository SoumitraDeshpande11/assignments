# Exoplanet Catalog Fetcher

A Dart console app that fetches mock exoplanet API data with null safety, `Future`, and `async`/`await`, handling null payloads and API errors.

## Concepts Demonstrated

- Nullable fields with null-safe display fallbacks
- `Future` returning functions with simulated latency
- `async`/`await` in a `for` loop
- `Future.wait` for parallel fetches
- Typed `on` catch blocks plus a general `catch`
- Null payload and exception handling

## Run

```bash
dart pub get
dart run lib/main.dart
```
